# Active Directory VMware Home Lab

## Project Overview

Built a simulated Active Directory environment using Windows Server 2022 in VMware Workstation. The lab focused on managing users, security groups, organisational units and implementing Group Policy settings within a Windows domain.

## Tools Used

- VMware Workstation
- Windows Server 2022
- Active Directory Domain Services (AD DS)
- Group Policy Management

## Tasks Completed

### 1. Active Directory Management
- Created an Active Directory domain (`Cemhousein.Local`).
- Created organisational units for Europe, Asia and USA.
- Created and organised user accounts.
- Created security groups, including IT and Finance.

### 2. Group Policy Management
- Created and configured multiple Group Policy Objects (GPOs).
- Configured password policy settings, including password length, complexity and expiry.
- Configured removable storage restrictions.
- Created policies for drive mapping and desktop wallpaper.

### 3. Security and Administration
- Managed user accounts and security group membership.
- Organised domain resources using organisational units.
- Configured security policies through Group Policy Management.

## Skills Demonstrated

- Active Directory administration
- User and group management
- Organisational unit management
- Group Policy configuration
- Password policy administration
- Windows Server 2022
- VMware virtualisation
- Basic domain administration
